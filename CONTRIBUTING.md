# Contribution Guidelines

## How to Contribute

1. Crea una branca nova a partir de `main`.
2. Fes els canvis i comprova l'estat del repositori amb `git status`.
3. Obre un *Pull Request* cap a `main` posant `Resolves #1`.

## Reporting Bugs

Obre un problema nou explicant els passos per reproduir l'error.

## Pull Request Process

Revisa els canvis, posa un missatge de *commit* clar i fes *merge* quan estigui llest.
